# Portfolio visual direction

Keep the existing galaxy and draggable orbit. Give the content a restrained personal archive treatment: flat dark surfaces, thin rules, readable body text, real project imagery, and section-specific layouts.

## Sources reviewed
- Space Grotesk by Florian Karsten: https://floriankarsten.github.io/space-grotesk/ — distinctive monospace-derived details and readable proportional spacing. SIL Open Font License 1.1.
- IBM Plex: https://github.com/IBM/plex — IBM Plex Mono for short labels and section indexing, not long paragraphs.
- Phosphor: https://github.com/phosphor-icons/react — evaluated consistent icon weights; no extra dependency needed because the six main astronomical marks are original inline SVGs. Existing Lucide icons remain for familiar actions such as close, download, email and external links.
- W3C modal dialog pattern: https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/ — modal keyboard focus, Escape, and returning focus to the opener. Implemented with native dialog and showModal.

## Typography
Space Grotesk: names and headings. Inter: body text. IBM Plex Mono: short metadata. Fonts are bundled and self-hosted by next/font; visitors do not request them from Google.

## Content
Remove decorative skill ratings and generic slogans. Group skills by practical use and identify backend work as learning. Preserve existing project details, contact links, portraits, PDF, and orbit interaction. Do not invent clients, outcomes, testimonials or expertise.
